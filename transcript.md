## A real failure in disposable demo services

A running process does not prove that a service works. The assistant helps a Liara customer understand which service needs attention and what to do next. This recording uses two real, dedicated demo services on Liara. A separate owner-approved controller deliberately introduced the fault; this is not an accidental production outage. The genuine diagnosis completed before filming, and the recording reviews its stored result without requesting new inference. Narration is synthetic and some waits are shortened. During the failure, the storefront health endpoint returns 200 while the preview endpoint returns 502.

## Evidence, timestamps and limits

Before acting, the assistant distinguishes observations it can use from missing or invalid data. Evidence records its target, source and timing. Missing metrics never become healthy zeroes. Supplementary read-only footage recorded after recovery shows resource samples. A summary with inconsistent timestamps remains invalid; separate historical observations use only native samples from before receipt. Replica values are not summed. Future or invalid values are excluded from model input while raw series remain available for owner inspection. History alone does not establish current load or insufficient capacity.

## Deploy and verify

A READY release does not prove recovery. The assistant first waits for evidence that the expected release is actually serving, within a bounded deadline. It then sends three fresh spaced rounds to the original symptom endpoints. Success requires the expected build and request identity as well as passing responses. This final run records six checks across three rounds, roughly 28 seconds, and succeeds without a second deployment. Long preparation waits are compressed in the video; the observations and counts are real. Insufficient evidence would remain inconclusive.

The final recovery result is separate from the earlier diagnosis and includes completion time. This is an edited demonstration, not proof of a continuous uncut run or round-the-clock monitoring.
